# Game artwork

`crew.png` is the original RGBA atlas produced with the built-in image-generation tool for this game. It is stored with the game; playing does not call an image service. The renderer extracts each connected character silhouette once so weapons and capes that cross the nominal grid boundary are preserved. Individual selection portraits use the same silhouettes. Character artwork is an original generated fan interpretation of the One Piece characters requested for this game.

## Generation prompt

Use case: stylized-concept. Asset type: transparent 2x2 character atlas for an isometric dark pirate action RPG, plus character selection. Create a single square high-resolution PNG with a truly transparent background. Exactly four separated full-body characters, each fully contained and centered in an equal square quadrant, with generous transparent padding, no overlap across the halfway grid boundaries. Top-left: Monkey D. Luffy from One Piece, recognizable straw hat with red ribbon, messy black hair, red open vest, blue shorts, yellow sash, sandals, clenched fists and elastic brawler stance. Top-right: Roronoa Zoro, green short hair, open green swordsman robe, red sash, three swords with one held in his mouth, confident grounded stance. Bottom-left: Edward Newgate / Whitebeard, enormous muscular elderly pirate, iconic crescent white moustache, white captain's coat draped over shoulders, bare scarred chest, dark pants, holding a long bisento polearm. Bottom-right: red-haired Shanks, short red hair, small scars over left eye, black captain cloak, open white shirt, patterned cropped trousers, sandals, holding a curved saber in his right hand, missing left arm. Style: premium painterly game character art, crisp sculpted silhouettes, rich readable material detail, original polished rendering of these characters. Full-body three-quarter front view seen slightly from above for an isometric action RPG, all face toward bottom-right, same camera and lighting. Warm golden rim light with cool teal shadow, dramatic but readable, no gore. Neutral ready poses, feet fully visible near bottom of each quadrant, all equipment contained inside each own tile. No background, no ground, no drop shadows, no text, no UI, no dividers, no watermark. This must be a useful game sprite atlas, not a screenshot.

## Enemy artwork

`enemies.png` is a second RGBA atlas generated with the same built-in image-generation tool. Top-left is a marine raider; top-right a flintlock corsair; bottom-left an armored enforcer; bottom-right a Haki captain. The renderer isolates the silhouettes once and retains procedural fallbacks if an asset cannot load. Both source atlases are 1254 × 1254 pixels.

### Generation prompt

Transparent 2x2 sprite atlas of FOUR full-body enemy characters for a painterly isometric pirate action RPG. Actual alpha-transparent background, not a checkerboard. Same square image divided into four equal quadrants with generous empty transparent padding. Each entire figure including weapons must fit completely into its quadrant, no overlaps. TOP LEFT: Marine raider, white cap, navy-blue uniform, white sailor cape, leather boots, cutlass in right hand. TOP RIGHT: flintlock corsair, rugged brown long coat, tricorn hat, red scarf, holding an old flintlock pistol. BOTTOM LEFT: Ironjaw enforcer, hulking armored pirate brute, dark iron shoulder armor, weathered brown-red coat, holding a heavy short iron hammer, menacing but no gore. BOTTOM RIGHT: Haki captain, formidable pirate captain in dark purple embroidered military coat, gold epaulets, black boots, dark hair, scar, curved sword glowing subtly crimson. These are original pirate enemies, NOT specific copyrighted characters. Art direction: polished high-end painterly game sprites, sculpted realistic fabric and armor, dramatic golden rim light and cool teal shadows, strong grounded silhouettes, same slightly elevated three-quarter front camera as an isometric Diablo-like action RPG, facing bottom-left. Detailed faces and equipment readable at 100 pixels tall. No chibi, no simplified cartoon, no giant heads. Neutral battle-ready poses. All boots fully visible at bottom of each quadrant. Weapons compact and contained. No ground, no background, no shadows, no border, no text, no UI, no watermark. Output real RGBA PNG transparency.
