# Activate Math online PDF imports

Sign in to Google Cloud Shell using the account that manages Math's existing
backend. Authorise Cloud Shell if Google asks.

From the cloned Math repository, run:

```bash
bash rapid-import/deploy-cloud-shell.sh
```

Keep the terminal open until setup finishes. If it stops, resolve the displayed
error and rerun the same command. Do not paste credentials into chat.

Open Math Practice, reload, and sign in as administrator. In Rapid Add, select
two small PDFs, including a question spanning pages. Wait until both uploads
say “Stored online”. Close the browser, then reopen Math and check the online
jobs and complete questions in Vetting.
